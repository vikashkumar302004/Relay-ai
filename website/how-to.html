COMPLETE SETUP GUIDE

Install Relay.
Keep your thread.

Relay is currently installed manually as an unpacked Chrome or Edge extension. Follow these steps once; after that, Relay appears directly inside your supported AI chats.

●
Why Developer mode?
Relay is in early access and is not yet listed in the Chrome Web Store. Developer mode lets Chrome load the downloaded extension folder safely from your computer.
INSTALLATION1. Download Relay2. Extract the ZIP3. Open Extensions4. Load the folder5. Pin Relay6. Move a chat
01

Download the extension

Click the button below. Chrome will download Relay-Extension-0.5.5.zip, normally into your Downloads folder.

Download Relay ↓
02

Extract the ZIP file

  1. Open your Downloads folder.
  2. Right-click Relay-Extension-0.5.5.zip.
  3. Choose Extract All….
  4. Keep the suggested location and click Extract.
Important: Do not select the ZIP file later. Chrome needs the extracted folder containing manifest.json.
03

Open Chrome Extensions

Open a new Chrome tab, paste the address below into the address bar, and press Enter.

chrome://extensions

Using Edge? Open this instead:

edge://extensions

Turn on Developer mode using the switch in the top-right corner.

04

Load the extracted folder

  1. Click Load unpacked.
  2. Open Downloads and select the extracted Relay folder.
  3. Choose the folder where you can see files such as manifest.json, content.js and background.js.
  4. Click Select Folder.
If Chrome shows an error: you probably selected the outer folder. Open it once more and select the inner folder that directly contains manifest.json.
05

Pin Relay to the toolbar

  1. Click the puzzle-piece Extensions icon beside Chrome's address bar.
  2. Find Relay.
  3. Click the pin icon so Relay stays visible.

You can now open Relay from the toolbar, and its on-page button will appear on supported AI websites.

06

Carry a conversation

  1. Open a chat on Claude, ChatGPT, Gemini or Perplexity.
  2. Click the Relay button and let it detect the visible conversation.
  3. Choose the AI you want to continue with.
  4. Relay opens that provider with a Context Capsule ready.
  5. Click Insert into this chat, review the text, then send it yourself.
Your control: Relay never enters your passwords and never sends a message automatically.

QUICK FIXES

If something doesn't appear.

Relay button is missing

Refresh the AI page after installation. Also confirm Relay is enabled on chrome://extensions.

“No readable messages” appears

Open an actual conversation, wait for it to finish loading, then reopen Relay and retry detection.

Chrome says manifest is missing

Select the extracted inner folder that directly contains manifest.json—not the ZIP or its outer wrapper folder.

Extension stopped after an update

Download the newest ZIP, extract it, remove the old Relay card from Extensions, and load the latest folder again.
